# Evidence Atlas visual direction

Historical design, superseded by [Signal Studio](signal-studio-design.md).

OpsVerse uses an editorial field-guide identity to distinguish it from the other
portfolio projects: warm ivory, dark ink, cobalt wayfinding and copper observation
markers. Georgia display type contrasts with clear sans-serif UI text and compact
monospace source material. All fonts are local system fallbacks; no font/CDN request.

The hero's original SVG maps observation to pinned evidence and a human-reviewed
brief. It is explicitly an illustration, not cluster telemetry or an agent trace.
The observation form resembles a field worksheet; selected evidence uses a quieter
sage surface. Evaluation pages use restrained numerical exhibits, while engineering
decisions follow an editorial reading sequence instead of repeating dashboard cards.

Retain readable contrast, visible focus rings, 44-pixel primary controls, bounded
source excerpts, mobile wrapping, and reduced-motion support. No business metrics,
customers, diagnosis accuracy or model capability are introduced by the visual layer.
The same existing retrieval/export/retry/keyboard contracts must continue to pass.
Remote browser evidence includes six routes at three widths and an actual populated
mobile investigation. Browser control on the owner's computer remains prohibited.

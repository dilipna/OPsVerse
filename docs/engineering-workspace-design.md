# Engineering Workspace — white and teal

The user explicitly selected a clean white-and-teal engineering workspace with
bold sans-serif typography. This replaces Signal Studio's plum/lavender/lime design.

- White canvas and header, teal controls/active navigation, restrained field borders.
- Plus Jakarta Sans headings, Inter UI, retained IBM Plex Mono diagnostic/source text.
- Compact introduction and neutral workflow guide, not a large decorative hero stage.
- Following explicit feedback that the structure still looked the same, the current
  application shell uses desktop left navigation, a compact workbench header,
  full-width diagnostic intake and evidence below it. The introductory hero and
  workflow illustration are removed from the application route. Evidence passages
  form a desktop review grid and stack on mobile. Small screens use a top navigation
  bar and stacked fields. Browser geometry checks enforce this structural change.
- White intake panel, pale-teal evidence surface, crisp source cards and metric displays.
- Shared typography/palette for all eight public routes, including research archives.

Fonts are self-hosted WOFF2 with pinned official originals and OFLs in public/fonts.
Archive exports default to the selected light appearance; the existing dashboard
toggle still offers an explicit dark variant. Canonical research scripts/claims stay
unchanged. Existing font-loading, raw-asset identity, responsive, keyboard, retrieval,
export and archive tests continue to gate publication. No browser/desktop control on
the owner's computer and no paid/model call or hosting-setting change.
